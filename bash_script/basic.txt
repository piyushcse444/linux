11) Command Line Arguments

        Special vars:
                        Variable	Meaning
                        $0	        script name
                        $1	        first arg
                        $#	        number of args
                        $@	        all args
                        $$	            PID    

        eg :- 
                #!/bin/bash
                 echo "Hello, $1! You are $2 years old."

                    $ ./greet.sh pete 30
