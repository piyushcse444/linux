5) Command Line Arguments
        Special vars:
                        Variable	Meaning
                        $0	        script name
                        $1,$2,....	first arg, second arg .....
                        $#	        number of args
                        $@	        all args
                        $$	            PID    
                        $?              exit status of last command
                                                        0 = success  non-zero = failure

        eg :- 
                #!/bin/bash
                 echo "Hello, $1! You are $2 years old."

                 Run it:
                    $ ./greet.sh pete 30
                    output:-
                    Hello, pete! You are 30 years old.
