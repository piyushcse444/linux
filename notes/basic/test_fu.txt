1) '>' -> redirection operator.
        It intercepts the data heading to stdout and sends it to a new destination
        echo "piysuh" > name.txt :- override piyush in name.txt

2) >> -> append in file

3)  < -> stdin 
       eg:- cat < peanuts.txt > banana.txt  

4) 2> -> Represents stderr    ;   0 -> < , 1-> > , 2 -> stdin
    cat is_file_exists > succes.txt 2> error.txt
    cat is_file_exists &> status.txt 
    cat is_file_exists &> /dev/null -> if we don't need to store the output

5)  | -> pipe 
        It takes the standard output (stdout) of the command on its left 
        and uses it as the standard input (stdin) for the command on its right. 

        eg :-
            history | grep "ls"

6)  tee -> read from stdin and write in both stdout and file
           eg :-
                history | grep cd | tee directory.txt | wc -l 
                    -> save all cd related command and show only line count

7)  env -> show all environment variable set in that session
            
            1) To set environment variable
                    my_env_var=my_value
                    export my_env_var
            2) To view env variable 
                    env | grep my_env_var or echo $my_env_var
            3) To remove environment variable
                unset my_env_var
            4) To make env variable persistant
                    nano ~/.bashrc -> paste (EXPORT my_env=value)
                    source ~/.bashrc 
            5) $PATH -> which ls -> tells the path of ls          
                    -> just add any executable file in it and you can run it from anywhere

8)  cut ->
             1) cut -c n sample.txt -> outputs the nth character from each line of the file
                                       cutting by character
             2) cut -f n -d ';' sample.txt  -> first split the text with delemiter then print nth string
                cut -f  sample.txt -> by default the delimeter is tab    
             3) cut -c -n -> shows first n character    
             4) cut -c n- -< shows character from n+1 th to end.

9)  paste ->
             1) paste -d ; -c sample.txt -> combine all limes with delimeter ;
                paste -c sample.txt -> by default delimeter is tab


10) head  -> 
             1) head -n 12 sample.txt -> only show first 12 lines in sample.txt
                head sample.txt -> by default it shows first 10 lines
                head -n -12 sample.txt -> show every line execpt last 12 lines

11`) tail -> 
             1) tail -n n path -> shows last n lines
                 tail  path -> by default it print last 10 lines
                 tail -n -20 path -> print from 21th line to end
             2) tail -f -n n path   -> Real-Time File Monitoring with tail -f
                                        it(-f) waited for real time change  i.e continueous Monitoring
12)   expand -> converts tabs character into 8 spaces
                echo -e "my\tname\tis\tpiyush\tkumar" > expand.txt
                expand expand.txt > output.txt
                expand -t 30 expand.txt -> replace 30 space for 1 tab
                cat -T output.txt
      unexpand -> converts spaces back to tab
                  unexpand -a result.txt

13)   sort -> sort a file
                sort file.txt -> sort in ascending order (based on string0)
                sort -r file.txt -> sort in decending order (based on string0)
                sort -n file.txt -> sort on the basic of number
                sort -u file.txt -> sort and remove duplicate             

14)   split -> split a larger file into multiple smaller file
                split file.txt -> split at every 1000 lines
                split -b 1M file.txt file_part_ -> the splitted file name 
                                                start with file_part_ and max_size = 1M
                                cat file_part_* >joined_file.txt -> join
                                md5sum file.txt == md5sum   joined_file.txt             
                                     

15)  wc  -> word count
            wc text.txt -> output -> no.of (lines, words, bytes)
            -l -> shows only line count
            -w -> shows o4490 pts/1    00:00:00 bashnly word count 
            -c -> shows only byte count
             
16) nl -> numbering lines
           nl file,txt -> add numbers in each line

17) grep -> searches for a pattern within a file.       
        grep -e "-v" -e "-p"  /path/to/some/file.conf -> for more advance serach -e is used
        grep -i  -> case insensitive
        grep -c fox sample.txt -> count matching line
        grep -o fox sample.txt -> show eaxct part of line that matches the pattern
        grep -f pattern.txt sample.txt -> search multiple pattern from pattern.txt file
        ls /somedir | grep '.txt$' -> find all file ending with .txt      

12) uniq -> remove duplicate only adjacent dublicate -> sorting is required
        sort file.txt | uniq -c  -> to count occurance of each line 
        uniq -u file.txt -> to print only those line which is unique
        uniq -d file.txt -> print only repeated line
