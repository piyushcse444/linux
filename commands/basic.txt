1) echo hello world
2) echo $shell -> show current shell name -> /bin/bash
3) pwd -> print working directory
4) cd -> change directory 
        /path -> absulote path
        path  -> relative path
        . (current directory): Represents the directory you are currently in.
                ./bts.bash	Runs file from current directory
                bts.bash	Searches PATH; may fail if current directory not in PATH
        .. (parent directory): Moves you one level up to the directory containing your current one.
        ~ (home directory): A shortcut to your personal home directory, like /home/pete.
        - (previous directory): Takes you back to the last directory you were in.

5) ls -> list directory 
        ls -> show list of file and directory in current directory
        ls path -> show list of files and directory of that path
        ls -a -> show hidden files (stands for all)
        ls -l -> details lsit of file in long formate 
                file permissions, number of links, owner name, owner group, file size, 
                timestamp of last modification, and the file or directory name.
                eg :- drwxr-x--- 7 pete penguingroup   4096 Nov 20 16:37 Desktop
        ls -r -> show sorting alphabetical in reverse order
        ls -t -> sort by modified time -> newest file first
        ls -h -> shows human readable size -> only work with -l

6) touch -> create new file or modify existing file timestamp
            touch new_file -> create new_file
            touch existing_file -> change last modified timestamp of that existing_file
            touch -r file1.txt file2.txt -> # Set file2.txt's timestamp to match file1.txt's timestamp
            touch -d "2023-01-01 12:30:00" file.txt -># Set the timestamp to a specific date and time

16) cp -> cp [SOURCE] [DESTINATION].  ( -r, -i, -p, -v )
            cp *.jpg /home/kali/Pictures
                    wildcard characters:-
                            1) * -> maches any sequence of character
                            2) ? -> matches any single character
                            3) [] -> matches any one of the character enclosed in[]
            cp -r folder1 folder2 -> copy all files and folder from folder1 to folder2 (recursive)
            cp -i file1 file2 -> promote for confirmation before overwritting  (interactive)
            cp -p -> also copy metadata (modified date and all) -> preserving flag

17) mv -> used to rename or move files or directory (-t , -i , -b . -v)
            mv file.txt file_updated.txt
            mv file_1 file_2 /somedirectory 
            mv -t /somedirectory file_1 file_2 -> allow to mention dest folder first
            mv -i source_file destination_directory -> promote for confirmation before overwritting  (interactive)
            mv -b file1 directory_with_file1 -> create a backup also if file is overwritting with name file1~
            mv -v file1 file2 /somedirectory -> print details of status 

18) mkdir -> make directory inside current directory

19) rm -> remove files and directory

20) find -> find files from a path -> find [path] [expression]
            find /home/kali -name puppies.jpg
            find                -iname puppies.jpg -> for case insensitive
            find                -type d -name config -> find only directory
            find                -type f -name '*.jpg' -> find only file                
            find                        -size +100M -> find file larger than 100mb
            find                        -size -10k -> find file smaller than 10kb (c -> byte , k -> kb , M , G)                         
            find                -mtime -7 -> Modified in the last 7 days
            find                -mtime +30 ->  Not modified in over 30 days
            find                -type f -name *.tmp time +7 -exec  rm {} \; -> delete all tmp file older than 7 days

29) alias -> we can give our shortcut name to command with flag 
            alias ll='ls -la' -> to give a alias temp for currents ession

            permanently make alias :-
                            1) Open the file in a text editor: nano ~/.bashrc
                            2) Add your alias definition to the file, just as you typed it 
                               on the command line:
                                                    alias ll='ls -la'
                                                    alias update='sudo apt update && sudo apt upgrade'
                            3) Save the file and exit the editor.
                            4) For the changes to take effect, you must either close and 
                               reopen your terminal or tell the shell to reload the 
                               configuration file using the source command:
                                        source ~/.bashrc
            unalias ll  -> remove alias ll
